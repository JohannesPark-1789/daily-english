# 주말 복습 카드 — 설계

> 작성: 2026-08-29 (KST)

매일 아침 받은 문장을 **토요일 오전 7시에 한 번 더**, 카드 넘기기로 복습한다.
카톡으로 링크를 받아 폰에서 바로 연다. 앱 설치 없음, 로그인 없음, 서버 없음.

---

## 1. 왜 이 구조인가

카톡 메시지 안에서는 카드를 넘길 수 없다 (텍스트 템플릿뿐). 그래서 **카톡은 링크만 나르고,
복습은 웹페이지가 한다.** 페이지는 정적 HTML 한 장이고 데이터는 그 안에 들어 있다.

```
data\phrases.tsv (번호·영어·쇼츠링크)   data\translations.tsv (번호·한글)
                    └──────┬──────────────────┘
              scripts\build-web.ps1
                           ↓
                  web\index.html   ← 단일 파일. 이것만 올리면 끝
                           ↓ 호스팅 (§4)
   토요일 07:00  scripts\send-weekly.ps1 → 카톡에 링크 발송
                           ↓
                  폰에서 열어 카드 복습 (기록은 폰 안에만 남는다)
```

## 2. 무엇을 복습하나 — 카드 범위 결정

세 가지 경로로 정하고, 위에서부터 우선한다.

| 순위 | 방법 | 쓰이는 때 |
|---|---|---|
| 1 | URL 파라미터 `?w=11,12,13,14,15` | 토요일 카톡 링크. 발송 스크립트가 **실제로 보낸 번호**를 박아 넣는다 |
| 2 | 날짜 계산 | 파라미터가 없을 때. 시작일(2026-08-24) + 평일 + `skipNos` 규칙으로 역산 |
| 3 | localStorage 누적 | "누적 연습" 모드. 방문할 때마다 그 주 번호를 누적 저장해 둔 것 |

1번이 가장 정확하다(빠진 날·건너뛴 번호가 그대로 반영된다). 2번은 링크를 잃어버렸을 때의 보험이고,
3번은 지금까지 받은 전체를 다시 훑는 용도다.

## 3. 학습 방식

요청하신 "앞뒤 선택 가능"에 더해, 효과가 검증된 것들을 얹었다.

- **기본 방향은 한글 → 영어.** 영어를 *만들어 내는* 연습이 알아보는 것보다 기억에 오래 남는다.
  영어 → 한글은 뜻 확인용으로 토글한다. 섞기 모드도 있다.
- **뒤집기 전에 답을 소리 내어 말한다.** 화면에 "먼저 답해 보세요" 안내를 둔다 (능동 회상).
- **3단계 자기평가** — 모름 / 애매 / 알아. 정답·오답 이분법보다 회상 강도를 잘 담는다.
- **못 맞힌 것만 다시.** 한 바퀴 끝나면 모름·애매만 모아 두 번째 바퀴를 돌린다.
- **누적 모드는 오답 가중.** 최근에 틀린 카드가 먼저 나오고, 이미 아는 카드는 가끔만 나온다
  (간격 반복의 단순화 버전).
- 각 카드에 **쇼츠 원본 링크** 버튼. 발음·뉘앙스가 헷갈리면 바로 확인한다.

기록(카드별 최근 결과·학습일)은 **폰의 localStorage 에만** 저장한다. 서버로 나가지 않는다
(`_shared/CONVENTIONS.md` §5 의 PWA 원칙과 같은 기준).

## 4. 호스팅 — 결정 필요

페이지는 어디든 올릴 수 있는 단일 파일이다. 후보:

| 방법 | 링크 열 때 | 비용 | 걸리는 것 |
|---|---|---|---|
| **Artifact** (claude.ai) | claude.ai 로그인 상태여야 열림 | 무료 | 폰에서 로그인 안 되어 있으면 불편 |
| **GitHub Pages** | 누구나 바로 열림 | 무료 | **공개 저장소**여야 함 (문장·번역이 공개된다) |
| Cloudflare Pages / Netlify | 누구나 바로 열림 | 무료 | 계정 하나 더 만들어야 함 |

기본값은 **Artifact** 로 잡아 두었다 — 지금 바로 쓸 수 있고 비공개다.
로그인 없이 열리는 링크를 원하면 GitHub Pages 로 옮기면 되고, `config.json` 의 `web.baseUrl`
한 줄만 바꾸면 발송 스크립트는 그대로 돈다.

## 5. 주간 발송

- 토요일 07:00, 작업 스케줄러 `daily-english-weekly`
- 그 주(월~금)에 실제로 보낸 번호를 `state\progress.json` 의 `sentNos` 와 로그에서 뽑는다
- 메시지 본문에 그 주 5문장을 나열하고, 버튼으로 카드 페이지를 연다
- 그 주 발송이 0건이면(휴가·PC 꺼둠) 보내지 않는다

## 6. 이 설계가 감수하는 것

- **번역은 초안이다.** 235개를 기계적으로 옮긴 것이라 뉘앙스가 어긋난 것이 섞여 있다.
  `data\translations.tsv` 한 줄씩 고치면 다음 빌드에 반영된다.
- **기록은 기기에 묶인다.** 폰에서 한 복습이 PC 에 보이지 않는다. 서버를 두지 않기로 한 대가다.
- **페이지는 자동 갱신되지 않는다.** 문장이나 번역을 고치면 `build-web.ps1` 을 다시 돌리고
  호스팅에 올려야 한다. 주간 발송은 링크만 보내므로 발송 자체는 영향받지 않는다.
