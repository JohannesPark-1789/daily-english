## 검증하지 못한 것

- **실제 발송은 테스트하지 못했다.** 토큰이 없어서 API 호출까지 가지 못한다.
  인증 후 `send-now.cmd` 로 한 번 보내 보면 끝난다. 실패하면 대개 이 셋 중 하나다:
  1. 동의항목 `talk_message` 가 앱에서 비활성 → 디벨로퍼스에서 켠다
  2. Redirect URI 불일치 → `.env` 값과 앱 설정이 글자 단위로 같아야 한다
  3. refresh token 만료(2개월 방치) → `setup.cmd` 재실행

## 손댈 때 주의

- 발송 함수는 `Send-DeKakaoMemo` 하나다. 친구톡/알림톡으로 갈 때 여기만 바꾸면
  스케줄·진행상태·템플릿은 그대로 재사용된다.
- 진행 번호는 `state\progress.json` 의 `nextNo`. 순서를 되돌리려면 이 값을 고친다.
- `send-today.ps1 -No 42` 는 진행 상태를 건드리지 않는다 (특정 문장 재발송용).
